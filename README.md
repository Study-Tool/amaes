# AMAES Toolkit

Standalone cross-browser extension (Chrome, Edge, Firefox) for AMA Online Education (AMAOEd / AMAES) Moodle portals.

- **Installer & Status Portal**: https://study-tool-amaes.pages.dev/
- **Public Answer Archive**: https://github.com/Study-Tool/database
- **Maintainer Runbook**: [HANDOFF.md](HANDOFF.md)

## Development

```bash
cd extension
npm install
npm test
npm run typecheck
npm run zip
npm run zip:firefox
```
